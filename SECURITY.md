# Security policy

This is a personal beta project. There is no support or response-time commitment.
Only the current default branch receives fixes. Releases do not provide an LTS promise.

Report a suspected vulnerability through [private vulnerability reporting](https://github.com/flowcool/booksys/security/advisories/new).
If reporting is unavailable, wait until the maintainer enables it. Do not open a
public issue with credentials, private links, local addresses or real catalogue data.
Use synthetic files and redact logs before sharing them. Include the affected
revision or image digest, expected behavior and a minimal reproduction.

Never attach downloaded comics, browser profiles, pyLoad credentials or source
archives from a real installation. The CI uses synthetic data. It has no lab access.
A vulnerability report does not authorize tests against another installation.
